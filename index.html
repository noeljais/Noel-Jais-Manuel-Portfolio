NoirPlay

A streaming platform, built and deployed during the internship

What it is

A full-stack streaming platform that I designed and deployed on AWS as part of my ipsr solutions internship.

How it works

A React and Tailwind frontend talks to a Node.js and Express backend with a PostgreSQL database. Everything runs in Docker containers, and Nginx is the only public entry point, so the backend ports are never exposed. PM2 restarts the server if it crashes.

Security

HTTPS with auto-renewing Let’s Encrypt certificates, parameterised SQL queries, bcrypt password hashing, JWT sessions with admin-only actions and security headers. It deploys through a GitHub Actions pipeline and is monitored with CloudWatch.

IP Subnet Calculator

A command-line tool for IPv4 subnetting

What it does

You enter an IPv4 address with a CIDR prefix, and it prints the network address, subnet mask, broadcast address, total addresses, usable hosts and the first and last usable IP.

Example

192.168.10.70/26 gives network 192.168.10.64, mask 255.255.255.192, broadcast 192.168.10.127 and 62 usable hosts.

How it works

It uses Python’s built-in ipaddress module, subtracts the network and broadcast addresses to count usable hosts, handles invalid input with try and except, and covers /0 to /30.

Network Security Toolkit

A modular Python toolkit for network basics and security auditing

What it is

A command-line toolkit written in Python to explore network fundamentals, connectivity testing, DNS resolution and basic security auditing. I built it as part of my hands-on Cloud Security Engineering learning journey.

The five tools

One interactive menu opens an IP subnet calculator, a TCP port checker, a DNS lookup tool that lists IPv4 and IPv6 addresses separately, a network diagnostics tool (ping, average response time, DNS and connectivity checks) and a local service auditor that checks common ports on localhost and names the services usually found there.

How it works

The main program uses Python’s subprocess module to launch each tool as a separate process, and each module handles one networking task. I tested it by starting a local web server and confirming that the port checker and the auditor saw the open port.

Scope

It is for education and authorised testing. It is mainly tested on Windows, only audits localhost and does not do vulnerability scanning.
